# NEON RACER — 霓虹狂飙

一款赛博朋克风格的 3D 悬浮艇竞速躲避网页游戏。纯前端、无需构建，打开即玩。

**▶ 立即游玩：[https://flufy3d.github.io/neon-racer/](https://flufy3d.github.io/neon-racer/)**

![NEON RACER](https://img.shields.io/badge/Three.js-0.160-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## 玩法

驾驶霓虹悬浮艇在无尽赛道上飞驰，躲避障碍、收集能量球，速度会越来越快——你能活多久？

- **连击系统**：2.5 秒内连续吃球叠加倍率（最高 ×6），分数滚雪球
- **擦身而过 +30** / **完美跳跃 +40**：高风险走位有额外奖励
- **机体进化**：收集能量球解锁 6 级形态，机体逐级展开鸭翼、装甲、磁力叉、背鳍与量子推进器
- **三首动态 BGM**：霓虹疾驰 → 御风行（国风电子）→ 极速脉冲（碎拍电子），每局自动轮换，刷新后延续顺序。节奏随车速加快，配器随速度、机体等级、连击与里程区域变化
- **分层音效**：合成筝笛、引擎与风噪，以及拾取、跳跃、擦身、护盾和撞击音效；关键事件会短暂压低音乐，拾取音随当前曲目音阶变化

## 形态与能力

形态升级门槛逐级拉大，越往后越难；每次进化机体会实时机械变形（部件展开 + 桶滚）。

| 形态 | 能量球 | 外形变化 | 能力 |
|------|--------|----------|------|
| T0 初始形态 | 0 | 青色 · 素机 | — |
| T1 引擎过载 | 18 | 绿色 · 折出鸭翼与散热鳍 | 横移强化 |
| T2 能量护盾 | 45 | 黄色 · 四片装甲板张开 + 能量环 | 护盾抵挡一次撞击（30 球充能） |
| T3 磁力场 | 85 | 橙色 · 伸出磁力叉与外侧引擎荚 | 自动吸附附近能量球 |
| T4 超载核心 | 140 | 品红 · 升起背鳍与外露反应堆、副翼下张 | 所有得分 ×2 |
| T5 量子跃迁 | 215 | 量子紫 · 背部推进器 + 破风长矛 + 光环与环绕晶体 | 空中二段跳 |

## 操作

| 平台 | 操作 |
|------|------|
| 键盘 | `← →` / `A D` 左右移动 · `↑` / `空格` 跳跃（T5 可空中再跳一次） |
| 触屏 | 按住左右半屏移动 · 上滑跳跃 · 两指分按左右半屏急停并锁定中线 |

支持桌面与移动端（iPad 横屏体验最佳），右下角 ⛶ 可进入全屏。

## 技术

- [Three.js](https://threejs.org/) 渲染 + UnrealBloom 辉光后期
- WebAudio 全程序化合成音效（无任何音频文件）
- HTML + 原生 ES 模块，无构建步骤，GitHub Pages 直接托管

## 本地运行

```bash
npx serve .
```

或 `python -m http.server 8000`，然后浏览器打开对应地址（ES 模块需通过 HTTP 访问）。

## 项目结构

```
index.html      页面骨架
style.css       全部样式
js/game.js      主逻辑（场景、循环、碰撞、输入）
js/audio.js     WebAudio 程序化音效
js/audio/       三首曲谱、合成音色、独立音频时钟
js/ui.js        HUD 与视觉反馈
```

## 音乐与音效

三首原创程序化曲谱各有 32 小节的主题、变奏和收束。国风曲以五声音阶和模拟筝、笛的音色搭配电子鼓与低音，不使用外部音频文件。每局保持一首主题；车速控制 BPM，机体等级与车速逐步增加配器层次，连击增加装饰音，跨区域和进化带来小节过门。

音符使用 WebAudio 时钟提前调度，赛道灯光读取同一节拍。切后台或失焦时音乐与引擎一起暂停，恢复时延续乐句；撞毁结束竞速音乐，重开清理上一局音效和混响。浏览器不支持音频时仍可静音游玩。所有音频模块均随 PWA 离线缓存。

验证：`node --test tests/audio.test.mjs`。`node tests/run-browser.mjs` 使用本机 Chromium 运行音频渲染、游戏联动与离线检查（Node 22+，可用 `CHROME_PATH` 指定浏览器）。通过本地 HTTP 服务访问 `tests/audio-browser.html` 可生成九段试听并保存 WAV；`window.__neon.audio` 提供只读音频状态用于检查。
